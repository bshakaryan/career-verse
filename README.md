# CareerVerse

CareerVerse — веб-приложение, в котором можно попробовать работу в IT через интерактивные задачи. Пользователь проходит один рабочий кейс в ролях поддержки, разработчика и QA, принимает решения и получает обратную связь.

**Деплой:** [career-verse-six.vercel.app](https://career-verse-six.vercel.app/)

## Что есть в проекте

- **Бесплатная миссия:** разобраться с жалобой клиента, оформить баг, выбрать исправление, проверить его и ответить пользователю.
- **Pro-кейс:** расследовать сбой оплаты, восстановить заказ и принять решение о релизе. Повторные платежи, возвраты и выбранное исправление реально меняют результат симуляции.
- **AI-разбор отчёта:** модель сравнивает текст с фактами кейса, отмечает ошибки с цитатами, объясняет их и предлагает исправленный вариант.
- **Быстрый вход в AI:** кнопка **Try AI feedback** на главной открывает редактируемый пример — проходить миссию заранее не нужно.
- **Обучение и прогресс:** вводные уроки, сохранение черновиков и история попыток в браузере.

## Как работает обратная связь

Оценка Pro-кейса рассчитывается по действиям пользователя: восстановлению заказа, проверке платежа, тестированию исправления, качеству выбранных выводов и решению о релизе.

AI отдельно анализирует свободный текст отчёта. Сервер восстанавливает состояние кейса из журнала действий и передаёт модели факты вместе с текстом. Ответ содержит сильные стороны, замечания и рекомендации. AI не меняет баллы или состояние симуляции; после редактирования текста предыдущий разбор помечается как устаревший.

## Бизнес-модель и метрики

**Модель:** бесплатный вводный кейс → Pro-подписка с новыми кейсами, практикой навыков и отслеживанием прогресса.

Значения ниже — гипотезы и цели из презентации команды, а не измеренные результаты MVP.

| Показатель | Цель / предположение |
| --- | --- |
| Цена Pro | $29 в месяц |
| Средний срок платной подписки | 4 месяца |
| Маржинальность | 75% |
| CAC — стоимость привлечения платящего пользователя | $25 |
| Маржинальный LTV — доход с пользователя с учётом маржи | $87 = $29 × 4 × 75% |
| LTV / CAC | 3,48× = $87 / $25 |
| Долгосрочная цель по ARR — годовой регулярной выручке | $100 млн, или около 287 тыс. платных подписчиков при $29 в месяц |

**Главная продуктовая метрика:** доля пользователей, завершивших всю миссию и итоговую рефлексию по ролям. Дополнительно планируем измерять возврат на вторую сессию, завершение практики, конверсию из просмотра Pro в подписку, удержание платящих пользователей и AI-затраты на завершённую симуляцию.

Гипотеза удержания: новые кейсы → персональная обратная связь → практика слабых навыков → видимый прогресс → возвращение. Платное удержание и стоимость привлечения ещё предстоит проверить на реальных пользователях.

## Техническая часть

| Часть | Технологии |
| --- | --- |
| Приложение и API | Next.js 16, React 19, TypeScript |
| Интерфейс | CSS, Headless UI, Lucide |

- `src/components/shopflow.tsx` — главная страница и навигация.

- `src/lib/shopflow/pro-case.ts` — логика Pro-кейса и расчёт результата.
- `src/components/ai-review-demo.tsx` — быстрый вход в AI-разбор.
- `src/components/pro-text-review.tsx` — редактор отчёта и отображение обратной связи.
- `src/app/api/pro-review/route.ts` и `src/lib/shopflow/pro-review-server.ts` — серверный обработчик AI-запросов.

## Локальный запуск

Нужны Node.js 22.13+ и pnpm.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Приложение откроется на [localhost:3000](http://127.0.0.1:3000).

Для AI-разбора добавьте в `.env.local`:

```dotenv
OPENAI_API_KEY=your_openai_api_key
OPENAI_REPORT_MODEL=gpt-5.4-mini
```

Ключ используется только на сервере. `.env.local` исключён из Git; шаблон переменных находится в `.env.example`. После изменения переменных перезапустите приложение. Без ключа миссии работают, но AI-разбор недоступен.

Для деплоя на Vercel добавьте эти переменные в **Settings → Environment Variables** и выполните новый деплой.

## Проверки и сборка

```sh
pnpm test        # Автотесты
pnpm typecheck   # Проверка TypeScript
pnpm build       # Production-сборка Next.js
pnpm start       # Запуск собранного приложения
```

Альтернативная сборка для Cloudflare Worker: `pnpm build:hosted`.

## Важно

Это MVP: платежи, возвраты и Pro-подписка учебные, реальные деньги не списываются. Для основных сценариев не нужны регистрация и база данных. Прогресс хранится на текущем устройстве и адресе сайта; очистка данных браузера удаляет его. AI вызывается только по кнопке, может ошибаться и даёт рекомендации, а не оценку профессиональной пригодности.
