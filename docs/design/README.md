# Career catalog prototype

`careerverse-catalog.html` is the interactive design prototype for the profession catalog. It includes search, category and availability filters, sorting, grid/list views, and a Project Management detail panel. Other professions are marked as coming soon.

This file preserves the original standalone design prototype. Its catalog is now implemented in `src/components/career-catalog.tsx` using Headless UI for field and sort listboxes, the availability switch, and role details dialog. The homepage opens the catalog; Project Management launches or resumes the existing practice at `#practice`. Other careers remain marked as coming soon.
