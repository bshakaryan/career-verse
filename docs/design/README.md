# Career catalog prototype

`careerverse-catalog.html` is the interactive design prototype for the profession catalog. It includes search, category and availability filters, sorting, grid/list views, and a Project Management detail panel. Other professions are marked as coming soon.

This prototype is a standalone HTML fragment with its own styles and scripts. It is not yet integrated into the React application or included in the production build. The published application currently runs the Project Management practice workflow.
